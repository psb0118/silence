# SILENCE — 침묵의 숲

1인칭 노이즈 기반 생존 공포 게임. 밤의 숲에서 **소리**가 너를 죽인다.
빠르게 돌아다니면 추적자가 너를 찾아낸다. 조용히, 신중하게 움직여 탈출하라.

## 실행

Node.js 18+ 가 필요하다. 최초 1회는 의존성을 설치한다.

```bash
npm install        # socket.io 설치 (최초 1회)
npm start          # 또는: node server.js
```

브라우저에서 <http://localhost:3000> 접속. 포트는 `PORT` 환경변수로 변경 가능.

## 협동 멀티플레이 (최대 4인)

멀티는 node 서버(`server.js`)가 켜져 있어야 한다. 단순 파일 서버(python http.server 등)에서는
멀티 버튼이 비활성화된다. node 서버로 접속하면 멀티가 자동으로 켜진다
(별도 시그널링 서버를 쓰려면 `?srv=서버주소` 추가).

1. 호스트 PC에서 `node server.js` 실행.
2. 전원 같은 주소로 접속한다:
   - 같은 PC: <http://localhost:3000>
   - 같은 와이파이의 다른 PC/폰: `http://<호스트LAN_IP>:3000`
     (Windows 방화벽에서 3000번 포트 허용 필요)
3. 시작 화면에서 **협동 멀티플레이** → **방 만들기** → 4자리 방 코드 확인.
4. 다른 사람은 같은 서버 주소로 접속해 방 코드 입력 → **참가**.
5. 호스트가 **게임 시작** (난이도는 호스트가 정한 값 적용, 호스트가 월드 소유).

참고: `?srv=` 없이 접속하면 싱글 전용이다 (멀티 버튼 비활성화). 인터넷 경유 시에는
이 저장소를 Render 등에 배포(`render.yaml` 포함)하고 배포 주소로 접속하면 멀티가 자동 활성화된다.
별도 서버를 쓰고 싶을 때만 `?srv=서버주소`를 붙인다.

## 게임 방법

- 맵 곳곳(잠긴 문 뒤 포함)에 흩어진 **차단기(퓨즈) 7개**를 모은다.
- **부가 미션 13개**(관측 5 · 테이프 5 · 경보 비콘 3)도 **전부 완수**해야 한다.
- 퓨즈 전부 + 미션 전부를 완수하면 전원이 들어오고 **출구 게이트**(시설 북쪽 마당 끝)가 열린다.
- 출구에 도달하면 탈출 성공.
- 추적자에게 잡혀도 **즉사는 아니다**. 체력(HP)이 남아 있으면 넉백과 함께 도망칠 기회가 주어진다.
  HP가 0이 되면 점프스케어와 함께 사망한다. (재시작하면 퓨즈·미션·아이템·HP 모두 초기화된다.)

## 난이도

시작 화면에서 선택한다 (`localStorage`에 저장).

| 난이도 | HP | 특징 |
| --- | --- | --- |
| 쉬움 | 3 | 느린 추적, 넓은 허용 오차 |
| 보통 | 2 | 기본 균형 |
| 어려움 | 1 | 빠르고 예리한 추적, 빠른 배터리 소모 |
| 악몽 | 1 | 검은 어둠(손전등 없으면 거의 안 보임) · **괴물 2마리** · 지도 없음 · 충전소 없음 · 야전 손전등으로만 재조명 · 잠긴 문은 열쇠+**비밀번호** · 괴물이 **눈을 뜨지 않음 — 오직 소리로만 추적** · 들켜도 숨으면 **50% 확률로 추적 해제** |

## 부가 미션 (전 난이도 공통 · 탈출 조건)

**13개를 전부 완수해야 격리 철문이 열린다.** 완료 현황은 좌측 HUD 칩에 표시되고, 승리·사망 화면의 통계에 `부가 미션` 행으로 기록된다.

| 미션 | 개수 | 방법 |
| --- | --- | --- |
| 관측 지점 기록 | 5 | 발광 기록대(파랑) 근처에서 `E` 길게(1.2초) — **기록 직후 기계음이 울려 괴물을 부른다** |
| 현장 테이프 회수 | 5 | 발광 테이프(주황) 근처에서 `E` 길게 — 조용한 편(소음 0.2) |
| 경보 비콘 정지 | 3 | 발광 비콘(빨강) 근처에서 `E` 길게(1.2초) — 사이렌 소음 0.4 |

- 시설 안(방·복도)과 외곽 마당(서·동·북·남)에 흩어져 있다.
- 전부 발광 메시라 어둠 속에서도 육안으로 찾을 수 있다.
- 미니맵에 표시되지 않는다 (지도는 구조물과 내 위치만 표시).
- 재시작하면 미션도 초기화된다.

## 비밀번호 (전 난이도 — 잠긴 문 2곳)

- **모든 난이도**에서 잠긴 문 2곳은 **열쇠 또는 비밀번호**로 열린다.
  - 열쇠가 있으면 바로 열리고, 열쇠가 없으면 비밀번호 키패드로 대체한다.
- 잠긴 문 2곳 (코드는 `CONFIG.doorCodes`):
  - **창고 문** — 파란 열쇠(`창고 열쇠`) 또는 코드 **4172**
  - **저장고 문** — 빨간 열쇠(`저장고 열쇠`) 또는 코드 **9260**
- 비밀번호 단서는 **「찢긴 메모」** — **기계창고 서랍**에서 나온다. `작업 일지` 메모는 탈출 목표(퓨즈) 단서.
- 오입력하면 소음이 새어 나간다. 키패드는 문 근처에서 `E` 길게로 열고, 숫자키 입력 후 `Enter` 확인.

## 스피드런 타이머

- 게임 좌상단에 경과 시간이 작게 표시된다.
- `Esc`로 일시정지하면 **타이머도 멈추고**, 재개하면 다시 흐른다.
- 사망/승리 화면의 기록과 동일한 값을 사용한다.

## 아이템

| 아이템 | 효과 |
| --- | --- |
| 배터리 | 손전등 충전 (+40, 스택 가능) — 악몽에서는 서랍에 나오지 않음. 배터리 **총 용량 120** |
| 야전 손전등 | 손전등 **교체** — 배터리 100%. 악몽의 소진=영구 고장에서 회복하는 유일한 수단 |
| 구급상자 | 체력 1 회복 |
| 연막탄 | 시야를 가리는 연막 — 괴물을 통과해 못 본다 |
| 소음장치 | 일정 시간 반복 소음으로 괴물을 유인 |
| 창고 열쇠 (파랑) | **잠긴 창고 문** 개방 — 소모되지 않음. 사용 시 문까지의 방향·거리 안내 |
| 저장고 열쇠 (빨강) | **잠긴 저장고 문** 개방 — 소모되지 않음. 사용 시 문까지의 방향·거리 안내 |
| 메모 (찢긴 메모 / 작업 일지 / 새겨진 숫자) | 단서 텍스트. 숫자키로 다시 읽기. "새겨진 숫자"는 악몽의 비밀번호 단서 |

`1–9` 키로 인벤토리 슬롯을 사용한다.

## 서랍

- `E` 길게 → 서랍 **열기**
- 열린 상태에서 아이템이 있으면 `E` 길게 → **획득** (서랍은 열린 채 유지)
- 다시 `E` 길게 → 서랍 **닫기**
- 열기/획득/닫기는 서로 독립적인 상태이며, 애니메이션 중에는 조작할 수 없다.

## 안전지대 (대피소)

- 안전지대 **안에서는 괴물이 너를 전혀 감지하지 못한다**. 시야·청각·추적·포획이 전부 차단된다.
- 안전지대에서 발생시킨 소음도 괴물에게 전달되지 않는다.
- 안전지대로 도망치면 추격이 해제되고, 괴물은 경계를 배회한다.

## 지도 (`M`)

- **자신의 위치와 맵 구조(방·벽·외곽 마당)만 표시한다.**
- 아이템·차단기·서랍·미션·괴물·출구 등은 표시하지 않는다.
- **악몽 난이도에서는 지도 자체가 없다** (`M` 무시).

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 (큰 소리) |
| `Ctrl` / `C` | 앉기 (가장 조용함) |
| `Space` | 점프 (착지음) |
| `F` | 손전등 토글 |
| `E` (길게) | 줍기 / 서랍 열기·닫기·아이템 획득 / 잠긴 문 / 부가 미션(관측·테이프·비콘) / 게이트 조작 |
| `Esc` | 일시정지 |

## 핵심 메커닉: 소음

- 화면 좌측 하단 **소음 게이지**가 발생하는 소리를 나타낸다.
- 이동·달리기·점프·착지 소리가 추적자에게 전달된다.
- **거리 기반 감지**: 소음의 세기에 비례해 멀리서 들린다. `청취 범위 = hearBase × 세기`.
  멀리 난 작은 소리는 무시되고, 가까운 큰 소리만 강하게 반응한다.
- **소음만으로는 자동 추격하지 않는다.** 가까운 강한 소리(또는 높은 점수)일 때만 `CHASE`,
  그 외에는 `INVESTIGATE`/`LISTEN`으로 접근해 확인한다.
- 벽/문 뒤에서 난 소리는 감쇠(약 45%)되어 전달된다.
- **마이크 입력**(설정에서 켜면)도 소음으로 반영된다 — 실제로 조용히 해야 한다.
- 시야에 들어오면 추격이 시작된다.

## 추적자 AI

- 격자 A* 경로탐색으로 장애물을 우회해 접근.
- 상태: `ROAM`(배회) → `INVESTIGATE`(소음 조사) → `CHASE`(추격) → `SEARCH`(수색).
- 시야(LOS)와 근접 감지, 소음 이벤트를 종합해 판단.

## 구조

```
silence/
├─ server.js            # 무의존 정적 서버
├─ render.yaml          # 배포 설정
└─ client/
   ├─ index.html        # HUD / 오버레이 / import map
   ├─ style.css
   ├─ vendor/three/     # Three.js r174 (로컬 벤더링, 오프라인 동작)
   └─ js/
      ├─ config.js      # CONFIG + QUALITY + DIFFICULTY 프리셋
      ├─ util.js
      ├─ inventory.js   # 아이템 정의 + 인벤토리
      ├─ world.js       # 지형/숲/구조물, 조명, 콜라이더, 퓨즈/게이트
      ├─ player.js      # 이동/충돌/스태미나/손전등/발소리
      ├─ noise.js       # 통합 소음 시스템 (이벤트 + 마이크)
      ├─ audio.js       # 프로시저럴 Web Audio 효과음
      ├─ monster.js     # 모델/애니메이션/A* 추적 AI
      ├─ ui.js          # HUD, 점프스케어, 토스트
      └─ main.js        # 렌더러/게임 루프/상태 관리
```

## 설정

인게임 설정에서 화질(그래픽), 마이크, 손전등 등을 조절할 수 있다.
값은 `localStorage`(`silence.settings`)에 저장된다.

## 디버그

`window.__silence` 전역으로 게임 상태에 접근할 수 있다
(`game`, `player`, `monster`, `noise`, `world`, `ui`, `THREE` 등).
`?capture=1` 로 접속하면 `preserveDrawingBuffer` 가 켜져 스크린샷 캡처가 가능하다.
