# SILENCE — 침묵의 숲

1인칭 노이즈 기반 생존 공포 게임. 밤의 숲에서 **소리**가 너를 죽인다.
빠르게 돌아다니면 추적자가 너를 찾아낸다. 조용히, 신중하게 움직여 탈출하라.

## 실행

의존성 설치가 필요 없다. Node.js 18+ 만 있으면 된다.

```bash
npm start          # 또는: node server.js
```

브라우저에서 <http://localhost:3000> 접속. 포트는 `PORT` 환경변수로 변경 가능.

## 게임 방법

- 맵 곳곳(잠긴 문 뒤 포함)에 흩어진 **퓨즈 7개**를 모은다.
- 모두 모으면 전원이 들어오고 **출구 게이트**가 열린다.
- 출구에 도달하면 탈출 성공.
- 추적자에게 잡혀도 **즉사는 아니다**. 체력(HP)이 남아 있으면 넉백과 함께 도망칠 기회가 주어진다.
  HP가 0이 되면 점프스케어와 함께 사망한다. (재시작하면 퓨즈·아이템·HP 모두 초기화된다.)

## 난이도

시작 화면에서 선택한다 (`localStorage`에 저장).

| 난이도 | HP | 특징 |
| --- | --- | --- |
| 쉬움 | 3 | 느린 추적, 넓은 허용 오차 |
| 보통 | 2 | 기본 균형 |
| 어려움 | 1 | 빠르고 예리한 추적, 빠른 배터리 소모 |
| 악몽 | 1 | 검은 어둠(손전등 없으면 거의 안 보임) · **괴물 2마리** · 지도 없음 · 충전소 없음 · 야전 손전등으로만 재조명 · 잠긴 문은 열쇠+**비밀번호** · 숨어도 거의 추적당함 |

## 스피드런 타이머

- 게임 좌상단에 경과 시간이 작게 표시된다.
- `Esc`로 일시정지하면 **타이머도 멈추고**, 재개하면 다시 흐른다.
- 사망/승리 화면의 기록과 동일한 값을 사용한다.

## 아이템

| 아이템 | 효과 |
| --- | --- |
| 배터리 | 손전등 충전 (+40, 스택 가능) — 악몽에서는 서랍에 나오지 않음 |
| 야전 손전등 | 손전등 **교체** — 배터리 100%. 악몽의 소진=영구 고장에서 회복하는 유일한 수단 |
| 구급상자 | 체력 1 회복 |
| 연막탄 | 시야를 가리는 연막 — 괴물을 통과해 못 본다 |
| 소음장치 | 일정 시간 반복 소음으로 괴물을 유인 |
| 창고 열쇠 (파랑) | **잠긴 창고 문** 개방 — 소모되지 않음. 사용 시 문까지의 방향·거리 안내 |
| 저장고 열쇠 (빨강) | **잠긴 저장고 문** 개방 — 소모되지 않음. 사용 시 문까지의 방향·거리 안내 |
| 메모 (찢긴 메모 / 작업 일지 / 새겨진 숫자) | 단서 텍스트. 숫자키로 다시 읽기. "새겨진 숫자"는 악몽의 비밀번호 단서 |

`1–9` 키로 인벤토리 슬롯을 사용한다.

## 서랍

- `E` 길게 → 서랍 **열기**
- 열린 상태에서 아이템이 있으면 `E` 길게 → **획득** (서랍은 열린 채 유지)
- 다시 `E` 길게 → 서랍 **닫기**
- 열기/획득/닫기는 서로 독립적인 상태이며, 애니메이션 중에는 조작할 수 없다.

## 안전지대 (대피소)

- 안전지대 **안에서는 괴물이 너를 전혀 감지하지 못한다**. 시야·청각·추적·포획이 전부 차단된다.
- 안전지대에서 발생시킨 소음도 괴물에게 전달되지 않는다.
- 안전지대로 도망치면 추격이 해제되고, 괴물은 경계를 배회한다.

## 지도 (`M`)

- 방 구조·벽·내 위치·차단기·잠긴 문·서랍만 표시한다.
- **괴물의 위치는 표시하지 않는다.**
- **악몽 난이도에서는 지도 자체가 없다** (`M` 무시).

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 (큰 소리) |
| `Ctrl` / `C` | 앉기 (가장 조용함) |
| `Space` | 점프 (착지음) |
| `F` | 손전등 토글 |
| `E` (길게) | 줍기 / 서랍 열기·닫기·아이템 획득 / 잠긴 문 / 게이트 조작 |
| `Esc` | 일시정지 |

## 핵심 메커닉: 소음

- 화면 좌측 하단 **소음 게이지**가 발생하는 소리를 나타낸다.
- 이동·달리기·점프·착지 소리가 추적자에게 전달된다.
- **거리 기반 감지**: 소음의 세기에 비례해 멀리서 들린다. `청취 범위 = hearBase × 세기`.
  멀리 난 작은 소리는 무시되고, 가까운 큰 소리만 강하게 반응한다.
- **소음만으로는 자동 추격하지 않는다.** 가까운 강한 소리(또는 높은 점수)일 때만 `CHASE`,
  그 외에는 `INVESTIGATE`/`LISTEN`으로 접근해 확인한다.
- 벽/문 뒤에서 난 소리는 감쇠(약 45%)되어 전달된다.
- **마이크 입력**(설정에서 켜면)도 소음으로 반영된다 — 실제로 조용히 해야 한다.
- 시야에 들어오면 추격이 시작된다.

## 추적자 AI

- 격자 A* 경로탐색으로 장애물을 우회해 접근.
- 상태: `ROAM`(배회) → `INVESTIGATE`(소음 조사) → `CHASE`(추격) → `SEARCH`(수색).
- 시야(LOS)와 근접 감지, 소음 이벤트를 종합해 판단.

## 구조

```
silence/
├─ server.js            # 무의존 정적 서버
├─ render.yaml          # 배포 설정
└─ client/
   ├─ index.html        # HUD / 오버레이 / import map
   ├─ style.css
   ├─ vendor/three/     # Three.js r174 (로컬 벤더링, 오프라인 동작)
   └─ js/
      ├─ config.js      # CONFIG + QUALITY + DIFFICULTY 프리셋
      ├─ util.js
      ├─ inventory.js   # 아이템 정의 + 인벤토리
      ├─ world.js       # 지형/숲/구조물, 조명, 콜라이더, 퓨즈/게이트
      ├─ player.js      # 이동/충돌/스태미나/손전등/발소리
      ├─ noise.js       # 통합 소음 시스템 (이벤트 + 마이크)
      ├─ audio.js       # 프로시저럴 Web Audio 효과음
      ├─ monster.js     # 모델/애니메이션/A* 추적 AI
      ├─ ui.js          # HUD, 점프스케어, 토스트
      └─ main.js        # 렌더러/게임 루프/상태 관리
```

## 설정

인게임 설정에서 화질(그래픽), 마이크, 손전등 등을 조절할 수 있다.
값은 `localStorage`(`silence.settings`)에 저장된다.

## 디버그

`window.__silence` 전역으로 게임 상태에 접근할 수 있다
(`game`, `player`, `monster`, `noise`, `world`, `ui`, `THREE` 등).
`?capture=1` 로 접속하면 `preserveDrawingBuffer` 가 켜져 스크린샷 캡처가 가능하다.
